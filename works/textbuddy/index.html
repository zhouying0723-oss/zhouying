安装方法

  1. 下载并解压 ZIP，将 TextBuddy.app 拖入“应用程序”。
  2. 首次启动时右键 TextBuddy，选择“打开”。
  3. 按欢迎向导授予辅助功能权限，并填写你的火山方舟 API Key 和模型 ID。
