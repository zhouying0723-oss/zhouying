GET STARTED

安装与首次使用

  1. 点击上方按钮下载 ZIP，双击下载的文件完成解压。
  2. 把 TextBuddy.app 拖入 Finder 的“应用程序”文件夹。
  3. 由于目前是未签名内测版，请不要直接双击；在“应用程序”中右键 TextBuddy，选择“打开”，再在提示框中点击“打开”。
  4. 按欢迎向导进入“系统设置 → 隐私与安全性 → 辅助功能”，打开 TextBuddy 的权限；授权后重新启动应用。
  5. 在任意应用中选中文字，按 ⌘E 即可改写并替换原文。默认 Agnes AI 可直接使用，火山方舟 API Key 为可选配置。

如果系统仍提示无法验证开发者或“应用已损坏”，请回到“应用程序”文件夹，再次使用“右键 → 打开”；若仍被拦截，可在终端执行 xattr -dr com.apple.quarantine /Applications/TextBuddy.app 后再打开。当前版本未签名、未公证，仅建议用于个人体验。

WHAT'S NEW

更新日志

TextBuddy 0.1.10 更新于 2026 年 8 月 8 日
  • 接入 Agnes AI 默认服务，不填写 API Key 也能直接使用。
  • 通过 Cloudflare Worker 安全转发请求，不在应用中保存 Agnes API Key。
  • 继续支持火山方舟 API Key 和常用模型配置，并优先使用个人配置。
  • 修复内测安装包的资源签名问题，避免 macOS 误报“应用已损坏”。
  • 增加菜单栏实时状态：处理中、已完成和处理失败都会有明确提示。
  • 新增“优先使用 Agnes AI”勾选项，配置火山方舟 API Key 后也可随时切换。
  • 新增“官话”语气，支持抓手、闭环、赋能、对齐、压实责任、走深走实等互联网与管理表达。
  • 修复辅助功能授权状态刷新，新增 Agnes AI 连接测试，并让两个测试按钮分别显示自己的加载状态。
  • 采用新的光标与银色星芒 Y2K 图标。
  • 快捷键为 ⌘E，支持任意可复制、粘贴的文字区域。
